Graphite Noir — Pencil Art Portfolio Website
![image alt](https://github.com/LakshithaSamaranayaka/Art-Gallery-Portfolio/blob/b79bf1aa6103808856359bc77bc6d698368cb4fd/frontend/public/homepage.png)

Graphite Noir is a premium pencil art portfolio website created to showcase my own graphite drawings in a professional and visually elegant way. The website presents realistic portraits, cinematic sketches, character-inspired artworks, and emotional pencil drawings with a dark luxury user interface.

Live Demo

Live Website: [vercel link](https://art-gallery-portfolio-weld.vercel.app)

Project Overview

This project was built to display my personal pencil artwork collection online. Instead of keeping drawings only as photos, Graphite Noir presents them through a responsive web platform with artwork categories, detailed artwork pages, social media links, and an admin upload system.

The main goal of this project is to combine my creativity as a pencil artist with my skills as a software engineering undergraduate.

Key Features

* Premium dark theme UI design
* Responsive mobile and desktop layout
* Artwork gallery with category filtering
* Artwork detail pages
* Admin artwork upload system
* MongoDB-based artwork storage
* Social media integration for Instagram, Facebook, and Threads
* Smooth hover effects and modern UI animations
* Vercel deployment

Technologies Used

Frontend

* React.js
* Vite
* Tailwind CSS
* React Router

Backend

* Node.js
* Express.js
* MongoDB
* Mongoose

Deployment

* Vercel

Purpose of the Project

Graphite Noir was created to showcase my pencil drawings professionally and allow others to explore my artwork collection online. Through this project, I improved my understanding of full-stack development, responsive UI design, backend API integration, database usage, deployment, and real-world portfolio presentation.

What I Learned

* Building a responsive React website
* Designing a premium user interface with Tailwind CSS
* Creating reusable components
* Connecting frontend and backend
* Managing artwork data with MongoDB
* Uploading and displaying artwork dynamically
* Deploying a full-stack project
* Improving visual design and user experience
